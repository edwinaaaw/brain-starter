# Resistance patterns

Choose one dominant pattern. Do not label the user.

| Signal | Pattern | Minimum intervention |
|---|---|---|
| The file is open but blank; the next move is unknown | No next step | Define the output, create a tiny structure, leave only the first field to fill |
| The user imagines finishing everything at once | Task too large | Name the current phase, ten-minute result, then two-minute opening move |
| They wait to feel ready or fear a poor result | Perfection/fear | Change the goal to “make something editable” |
| They report fog, exhaustion, or low capacity | Low energy | Reduce cognitive load or shorten the block; suggest recovery when starting is inappropriate |
| They keep switching tabs, tasks, or ideas | Competing pull | Park distractions, restate one target, return to the interruption point |
| An attachment, answer, decision, or person is missing | Blocked dependency | Search, draft a request, schedule follow-up, or find one parallel step |

If two patterns are plausible, intervene on the one closest to the first physical action. Ask a question only if choosing incorrectly would materially change the action.
