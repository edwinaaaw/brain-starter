# Field-tested patterns

Use these patterns as transfer rules, not scripts. Keep the next action specific to the user's actual context.

## Work research and outreach

- Convert a vague request such as “find acquisition channels” into explicit constraints before searching: audience, volume, price ceiling, conversion event, compliance, and information-disclosure boundary.
- Read the user's existing tracker before proposing more leads when it is available. Deduplicate by organization, account, contact, and prior outcome.
- Separate verified providers from merely claimed providers. State uncertainty and reject obvious mismatches instead of padding the list.
- Prepare search terms, comparison fields, outreach copy, or a shortlist. Preserve the user's approval of disclosure, price, and partnership terms.
- Count a start when the first qualified search is run, one real lead is verified, or one approved outreach message is sent—not when a long list is generated.

## Reporting and synthesis

- Read only the named chats, documents, or notes. Extract decisions needed, completed work, evidence, and unresolved items.
- Match the reader: place decisions first for a decision-constrained reader; compress progress when they prefer one sentence.
- Draft the report mechanically, but ask the user to verify sensitive claims and ownership.
- Count a start when an editable first section exists or the user verifies the first decision item.

## Exercise and body-based starts

- Check immediate constraints first: location, recent food, symptoms, injury, and available intensity. Do not diagnose.
- Use the user's familiar routine and environment. A walk home, changing clothes, opening the saved video, or doing two gentle minutes can be the opening action.
- When symptoms, pain, dizziness, breathing difficulty, or unsafe timing are present, reduce intensity or recommend stopping and appropriate care.
- Count a start when the user begins the warm-up or first safe movement—not when they promise to exercise later.

## General transfer rule

Find the smallest real-world state change that makes avoidance less likely. AI may remove search, formatting, sorting, and blank-page work; the user retains consequential judgment, bodily consent, learning retrieval, and authorship.
