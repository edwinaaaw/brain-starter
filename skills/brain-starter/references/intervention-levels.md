# Intervention levels

Use the lowest level that makes the first action possible.

| Level | AI action | Appropriate example |
|---|---|---|
| L1 | Point to the next action | “Open the brief and highlight the decision sentence.” |
| L2 | Break down the action | Turn “prepare meeting” into three concrete checks |
| L3 | Build a scaffold | Create headings, questions, checklist, or an empty reply structure |
| L4 | Co-create | User supplies judgments while AI structures and challenges them |
| L5 | Do mechanical work | Find an attachment, extract dates, format notes, draft an administrative reply |

Do not default to L5 merely because it is possible. Preserve the user's core judgment, learning attempt, original point of view, approval, and accountability. State briefly what AI completed and what remains theirs.
