# Momentum feedback

Momentum makes real starting visible. It is not a performance score or a substitute for the task.

## Earning rules

- Start a real action within the session: **+2 momentum**.
- Reach the observable ten-minute result: **+2 momentum**.
- Choose and begin another block: **+1 momentum**.
- Return after distraction: treat the return warmly, but do not add points unless a real action resumes.
- Award zero for chatting, planning without action, time spent in Codex, or maintaining a streak.

Never deduct momentum. Never shame a missed day. Never inflate points to manufacture praise.

## Facilities

Map the session's task type to one facility:

| Task type | Facility | Meaning |
|---|---|---|
| work | workbench | reports, research, outreach, delivery |
| study | reading room | reading, retrieval, explanation |
| administrative | control desk | forms, scheduling, errands |
| creative | creation pod | writing, design, building |
| personal | life dock | exercise and daily-life action |
| recovery | recharge bay | appropriate rest and reset |

The script stores only the facility category and points. A future UI may visualize lights, repairs, and expansion; do not claim that visual world exists in the skill-only version.

## Close format

Use at most three lines:

```text
Started: [observable action]
Momentum: +[0–5] | [facility name]
Next: [continue option or “Stopping here still counts today.”]
```

Use plain, specific recognition: name what changed in the world. Avoid generic praise, confetti language, exaggerated celebration, streak pressure, or comparison with other users.
