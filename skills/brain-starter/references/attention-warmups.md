# Attention warm-ups

## Default embedded layer

Every start silently includes:

1. **Goal compression:** one target, first visual location, first action, observable finish.
2. **Distraction parking:** accept a voice/text dump; classify each item as now, later, or no action. Do not turn every thought into a task.
3. **30-second re-entry:** after distraction, name the interruption point and one action possible within 30 seconds.

Do not present this as a lesson the user must complete before starting.

## Optional 2–5 minute refuel

Use only when explicitly requested as an attention refuel. Choose one exercise serving the present task:

- single-goal compression;
- distraction unload;
- task-switch reset: close the previous loop, name the new target, open its first surface;
- orienting/re-entry: notice three relevant visual details, then touch the exact next control or sentence.

End by entering the real task immediately. Do not use N-back, reaction games, clinical scores, intelligence claims, or a “never get distracted” standard. The trained behavior is returning.
